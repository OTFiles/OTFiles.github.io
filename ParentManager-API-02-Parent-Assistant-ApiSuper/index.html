发表于2026-08-14|更新于2026-10-10

② 手机端家长助手（api-super 域）接口

本分册对应原手册 第七章。
分析样本：家长助手 com.readboy.rbmanager v2.9.57 / v2.6.4。

最重要的结论：手机端家长助手与平板端家长管理不是同一套认证，也不是同一套能力。
平板端靠一个硬编码 APPSECRET 的 MD5 签名就够了；手机端走 getSn 签名 + 强制 token，
且独有能力是平板端没有的——时间管控、允许输入密码（allow_input_pwd）。
如果只想改平板上「能不能输入密码」，平板端自己是没接口的，必须借手机端这套（或直接改 SharedPreferences，见解绑专文 8.4.1）。

七、手机端家长助手（家长 App）api-super 域接口 ★新发现

来源：家长助手 v2.9.57 / v2.6.4（com.readboy.rbmanager，手机端家长 App）反编译。
域名 https://api-super.readboy.com/api/，与平板端完全不同的认证体系。
关键价值：平板端（parent-manage/parentadmin）没有时间管控、允许输入密码的修改接口（反编译 + 40+ 路径暴力探测均确认 404）；这两个功能只在 api-super 域有，且强制 token。

7.1 签名算法（Util 类的 getSn）

定位：家长助手（com.readboy.rbmanager）APK 内 Util 类的 getSn(String,String,String,String)；
该类在混淆后的 dex 中可能落在任意 smali*/ 目录，按方法名 getSn 全局搜索即可。

  • 已登录：arg3 = MD5(uid8)（uid 为家长账号 uid）
  • 登录时：arg3 = MD5(PACKAGE)，uid8 = "00000000"

7.2 认证流程（token 强制）

响应（MobileRegisterResponse）：

登录后所有请求带 **sn=getSn(uid8, ts, MD5(uid8)) + token=access_token**。

⚠️ 实测（2026-08）：不带 token 请求时，签名验证通过后返回 {"errmsg":"token无效","errno":8002}——token 无法绕过，必须登录。签名参数名是 sn（不是 signature），传平板端签名返回 7001「签名不能为空」，传错 uid 返回 7003「签名无效」。

7.3 请求方式、请求头与 ua 参数（★完整说明）

请求头：无任何自定义请求头！

检查项 结论（反编译确认）
Retrofit 注解 全部接口只有 @QueryMap，无 @Header/@Headers
OkHttp 配置 ApiRetrofit 只有 CommonInterceptor + 日志/缓存拦截器 + 10MB 缓存 + 超时，零 addHeader
参数位置 全部在 URL query string（GET 和 POST 都是 query，POST body 为空）
Content-Type 不强制（curl 无 header 也能通）
User-Agent 常规 UA 即可，服务器不校验

ua 参数（query 参数，不是请求头！）

  • ApiRetrofit$CommonInterceptor 自动给每个 URL 追加 ua=<值>（仅当 URL 不含 ua= 时）
  • 格式（反编译 Util.getOauthUAPro()）：
  • 示例：1/android10/NB-H90/com.readboy.rbmanager/290/5c3a1b2e...
  • 跳过条件：URL 已含 ua= 直接放行；URL 含 get_last_check_device 不追加
  • 非强制：实测不带 ua 也能收到业务响应（7001/7003/8002）——服务器不校验 ua

请求情况 响应

⚠️ 签名验证顺序：先验 sn（7001/7003），通过后再验 token（8002）。ua 不在验证链中。

7.4 时间管控接口（⭐ 平板端没有）

拉取时间管控配置

响应（TimeSettingResponse）：

  • total_time：每日管控总时长（秒，14400 = 4 小时）
  • periods[].start/end：自当天 0 点起的秒（28800 = 8:00，82800 = 23:00）
  • group：逗号分隔的星期（0 = 周日）
  • anti_addiction：防沉迷（使用时长/休息时长，秒）
设置时间管控
参数 说明
tid 已有配置 ID（修改时传，新建不传）
group 星期（逗号分隔，0=周日）
period_status 0/1 是否启用时间段
periods JSON 字符串 [{"start":秒,"end":秒}]（period_status=1 时传）
total_time 每日总时长秒（启用总时长时传）

响应：{ "errno": 0, "errmsg": "", "status": 1 }

其他时间接口
接口 说明
GET parent_control/time_switch 时间管控总开关（sn+token+imei+…）
GET parent_control/set_anti_addiction 设置防沉迷（use_duration/rest_duration）
GET parent_control/delete_time_setting 删除时间设置
GET parent_control/today_time_setting 今日时间设置

7.5 密码接口（⭐ 允许输入密码平板端没有）

修改 / 清除家长管理密码
  • new_pwd 为明文（trim 后直接传，无 MD5）
  • 清除密码：new_pwd=""（App 提示「已清除平板端家长管理密码」）
  • is_long_pwd：1=长密码
允许输入密码（⭐ 对应平板端 allow_input_pwd，设备端无此接口）
  • allow_input_pwd=1 允许输入密码；0 禁止（键盘点击 Toast「根据管控策略，本机禁止输入密码」）
允许启动密码（allow_pwd）

⚠️ 参数名对比：手机端 api-super 域用 allow_pwd；平板端 parent-manage 域（uploadAllowPwd）用 allow（见 4.4）——两个域参数名不同！

其他密码接口
接口 说明
GET parent_control/get_control_pwd 获取管控密码
GET parent_control/password_record 密码修改记录

7.7 与平板端差异对照

项目 平板端 parent-manage/parentadmin 手机端 api-super
签名 getSign2 / getSign（signature 参数） getSn（sn 参数）
认证 无 token，签名即身份 token 强制（登录后 access_token）
请求头 部分接口带 Authentication: 4G:<MD5签名> 认证头 无任何自定义请求头，仅 query 带 ua（见 7.3）
时间管控修改 ❌ 无 ✅ time_setting / set_time / time_switch / set_anti_addiction
允许输入密码 ❌ 无（uploadAllowPwd 实为 allow_pwd） ✅ change_allow_input_pwd
允许启动密码 ✅ uploadAllowPwd（参数 allow） ✅ update_allow_pwd（参数 allow_pwd）
密码修改 ✅ password/upload ✅ update_password（new_pwd 明文）
管控列表 ✅ controlApp/upload ✅ control_app / app_list
