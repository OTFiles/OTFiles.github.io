ZaralynControl 使用指南

这是什么

ZaralynControl 是一个基于读书郎家长管理 App（6.2.8 版本）反编译代码开发的管控修改工具。它维护一个自己的镜像数据库，通过双向同步机制覆盖家长管理 App 的本地数据库及云端配置，实现对被管控设备应用列表的自主修改。

适用人群：拥有设备所有权的家长，或技术研究者。
不需 root，但需要 ADB 安装一次（或通过文件管理器直接安装 APK）。

功能速览

功能 说明
镜像库权威 自己维护一个 Room SQLite 数据库，所有修改先写入镜像库，再同步给家长管理
本地双向同步 从家长管理 ContentProvider 拉取配置；修改后覆盖写入 Provider
云端双向同步 从 jpush/content 拉取云端配置；通过 controlApp/upload 上传管控列表
版本自动适配 自动检测新版（install_app_list disabled_state）和旧版（forbidden_app state）
后台自动同步 WorkManager 周期任务，默认 1 分钟，可配置 1~60 分钟
远程设备管控 在设置中手动输入其他设备的序列号，仅发请求不修改本机数据库
失败重试 云端请求失败自动重试 3 次，全程 debug 日志
日志可复制 应用内日志面板，点击复制按钮即可导出

安卓端使用指南

第一步：下载安装

  1. 前往 Releases 页面 下载最新版 APK（ZaralynControl-v*.apk）
  2. 在设备上安装（如遇「未知来源」提示，在设置中允许安装）
  3. 打开应用，授予 READ_PHONE_STATE 权限（用于获取设备序列号，云端同步必需）

第二步：从家长管理拉取配置

打开应用后，默认进入「管控列表」页面：

  1. 点击顶部的 「从家长管理拉取」 按钮
  2. 应用会自动检测家长管理版本（新版/旧版）
  3. 从 AppContentProvider 读取 install_app_list 或 forbidden_app 表
  4. 数据写入镜像库，显示在列表中

拉取成功后，你会看到统计卡片：共 X 项 / 允许 Y / 禁用 Z。

第三步：修改管控列表

每个应用显示为一个卡片，包含：

  • 应用名称（或包名首字母色块）
  • 包名
  • 允许/禁用 开关（MD3 风格 Switch）

操作方式：

  • 切换开关 → 立即更新镜像库（状态标记为「未同步」）
  • 点击「+」按钮 → 输入包名添加新应用（默认允许）
  • 点击删除按钮（✕）→ 从列表移除

搜索与筛选：

  • 搜索框：按包名或名称实时过滤
  • 筛选 Chip：全部 / 仅允许 / 仅禁用

第四步：覆盖写入家长管理

修改完成后：

  1. 点击 「覆盖家长管理」 按钮
  2. 应用将镜像库数据写入家长管理 ContentProvider（install_app_list 或 forbidden_app）
  3. 家长管理 App 下次拉取云端配置时，如果云端未修改，则不会覆盖

第五步：云端同步（可选）

在「密码管理」页面：

  • 从云端拉取：调用 jpush/content?get_all=1 全量拉取，更新镜像库
  • 上传云端：调用 controlApp/upload 上传管控列表到服务器

注意：云端上传需要正确的签名（使用反编译得到的硬编码密钥），应用自动计算。

设置页说明

在「设置」页面可以配置：

选项 默认 说明
自动同步 开启 后台 WorkManager 周期扫描并覆盖
云端同步 关闭 周期同步时同时上传云端
扫描间隔 1 分钟 SeekBar 1~60 分钟可调
远程设备序列号 空 输入其他设备序列号后，仅发请求不修改本机

技术原理

架构

镜像库表结构

表名 内容
mirror_control_list 管控应用列表（package_name, disabled_state, …）
mirror_user_info 家长密码（password, is_long_pwd, is_allow_input_pwd）
mirror_switches 控制开关（switch_name, status）
mirror_meta 元信息（数据库表结构版本等）

签名算法（来自 com.readboy.parentmanager.core.http.Sign 反编译）

关键接口

接口 用途
GET http://parent-manage.readboy.com/api/v1/jpush/content?get_all=1 全量拉取云端配置
POST https://parentadmin.readboy.com/v1/appinfo/controlApp/upload 上传管控列表（Header 携带 control_list JSON）
POST http://parent-manage.readboy.com/api/v1/password/upload 修改家长密码
GET https://parentadmin.readboy.com/v1/machine/cancel_bindings 解绑设备（见 ZaralynUnbind）

注意：响应结构已根据真实抓包验证修正。所有配置字段在 data 对象内，control_list 在 data.app_control.control_list。
