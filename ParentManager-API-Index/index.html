家长管理生态全部网络接口：索引与总览

为什么拆成多篇：整套材料覆盖 7 个应用（家长管理 6.2.8、家长助手、应用商店、系统设置、killapp、DreamUpdate、personalsetting）、
数百个接口与若干整机行为链。原先挤在一篇 1800 行的长文里，检索困难；现按「协议层 → 业务域 → 应用」拆为 4 篇分册，
章节编号沿用原稿的 〇～十二，所以你在任何地方看到「见 11.6」都能直接对号入座。

本系列的目标：万一厂商倒闭 / 服务器关闭，这份材料要足够让人自建服务端、理解设备行为、或做本地替代实现。
因此每篇都尽量做到「不看原始 APK 也能复现结论」——关键证据（smali 片段、常量、字段名、类路径、行号、抓包样本）都内联在正文里。

方法篇

  • 逆向复现指南：怎么反编译、怎么按类全限定名定位代码、怎么核对常量与行号、抓包怎么抓、smali 字节码怎么看。本文档所有结论都能用它独立验证。

一句话结论（先看这个）

  1. 平板端全部接口无 token/会话，身份 = MD5(秒时间戳 + APPSECRET + MD5("parent-manage"))，密钥硬编码在 APK 里 → 任何人可伪造。
  2. jpush/content 的配置全在响应 data 对象内（不是顶层），且返回空 control_list 不等于放行——设备对空数组不做任何处理。
  3. 手机端家长助手是另一套体系（api-super 域，getSn 签名 + 强制 token），能力和平板端不对等：时间管控、允许输入密码等只有手机端能给。
  4. 应用商店安装管控是”下载等级 + 已安装列表 + 云端 control_list”三方判定，改单一处会被下一次全量拉取覆盖。
  5. USB 调试选项被永久隐藏，是否显示由家长管理的 un_mall_app_state 表（对应云端 allow_unknown_app）决定，另有 _wfad_ WiFi 高级选项暗门。
  6. OTA（ota.readboy.com/update.php）完全无鉴权，HTTP 明文；机型库按 (model, board, android, chipset) 四元组精确匹配，id 恒为 1000、通道由 debug 承载。
